# WILKER Planner — versão final com trilha ampliada

Projeto pessoal local para planejamento, tarefas, cronograma, finanças, investimentos e acompanhamento de evolução em tecnologia.

A aba **Meu plano** agora traz cada fase aberta, com módulos, projetos e uma biblioteca pessoal de materiais: jogos, vídeos, prática interativa e referências.

## Aplicar no projeto do PC

Extraia este pacote e execute somente:

`APLICAR_WILKER_FINAL_NO_GIT.cmd`

O script usa `C:\Users\PC\Desktop\wilker-planner`, cria backup do `index.html`, copia os arquivos finais, valida o JavaScript e publica no Git.

Depois, rode `npm start` dentro de `C:\Users\PC\Desktop\wilker-planner` e use `Ctrl+F5` no navegador.

V3: restaura a Trilha TI por categorias e fases, com jogos, vídeos, prática, referências, projetos e bloqueio visual com cadeado nas fases futuras.
